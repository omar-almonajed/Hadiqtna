# دليل التوصيل الكهربائي والعتاد | Hardware Wiring & Electrical Safety

## 1. توافق الحساسات فوق الصوتية (HC-SR04 و JSN-SR04T)
لم يُحسم طراز الحساس النهائي بعد؛ ولذلك صُمم الكود البرمجي في `firmware/esp32/include/config.h` ليكون معيارياً وقابلاً للتهيئة عبر المتغير `SENSOR_MODEL`.

| الخاصية | HC-SR04 | JSN-SR04T (المقاوم للماء) |
|---------|---------|----------------------------|
| البيئة المناسبة | نماذج اختبارية أو مغلفة | **موصى به للحاويات الخارجية** |
| جهد التغذية (VCC) | 5V | 5V |
| جهد إشارة Echo | **5V** (غالباً) | **5V** (حسب الإصدار) |
| المنطقة العمياء (أقل مسافة) | ~2 سم | **~20 سم** (يجب أخذها بالحسبان عند المعايرة) |

---

## 2. تحذير كهربائي إلزامي قبل توصيل أي حساس بلوحة ESP32
تعمل منافذ الإدخال والإخراج في لوحة **ESP32** بجهد **3.3 فولت فقط** وليست محمية ضد جهد 5 فولت. توصيل طرف `ECHO` بجهد 5 فولت مباشرة إلى منفذ GPIO قد يتلف المعالج.

### الحل الإلزامي: مقسم جهد (Voltage Divider) أو محول منطق (Level Shifter)
استخدم مقاومتين لخفض جهد `ECHO` من 5V إلى ~3.33V:

```text
Sensor ECHO (5V) ──[ 1 kΩ ]──┬──► ESP32 GPIO 18 (3.3V آمن)
                             │
                          [ 2 kΩ ]
                             │
                            GND
```
*(معادلة الجهد: `5V × 2kΩ / (1kΩ + 2kΩ) = 3.33V`)*

## 3. جدول التوصيلات الافتراضي (`config.h`)

| المكوّن | الطرف في المكوّن | المنفذ في ESP32 | ملاحظات الحماية |
|---------|-------------------|----------------|-----------------|
| حساس المسافة | `VCC` | `5V / VIN` | تغذية مستقرة 5 فولت |
| حساس المسافة | `GND` | `GND` | أرضي مشترك مع اللوحة |
| حساس المسافة | `TRIG` | `GPIO 5` | يعمل مباشرة بنبضة 3.3V |
| حساس المسافة | `ECHO` | `GPIO 18` | **عبر مقسم جهد 1kΩ / 2kΩ** |
| مؤشر LED أخضر (0–49%) | الأنود (+) | `GPIO 25` | عبر مقاومة `220Ω - 330Ω` |
| مؤشر LED أصفر (50–79%) | الأنود (+) | `GPIO 26` | عبر مقاومة `220Ω - 330Ω` |
| مؤشر LED أحمر (80–100%) | الأنود (+) | `GPIO 27` | عبر مقاومة `220Ω - 330Ω` |
| جميع مؤشرات LED | الكاثود (-) | `GND` | أرضي مشترك |
