# حديقتنا | Hadiqtna

منصة عربية متكاملة لإدارة الحدائق العامة، الحاويات الذكية، البلاغات الإلكترونية، والمراقبة الميدانية عبر إنترنت الأشياء (IoT). المشروع يجمع بين واجهة web تفاعلية، خادم Node.js/Express، قاعدة بيانات Firestore، ومعدّات ESP32 لإرسال قراءات الحاويات وتحليلها مباشرة.

## نظرة عامة

تُصمّم منصة حديقتنا لمؤسسات المدن والحدائق العامة لتسهيل:

- مراقبة حالة الحاويات الذكية في الوقت الفعلي
- متابعة نسبة الامتلاء والإنذارات التشغيلية
- إدارة الصيانة، المهام، والتحذيرات
- استقبال شكاوى وملاحظات المواطنين
- عرض لوحات إحصائية وتحليلات الأداء
- دعم عمليات التشغيل من خلال واجهات عربية/إنجليزية ومواقع محمية حسب الدور

المنصة تدعم نموذجين أساسيين:

- وضع العرض التوضيحي (Demo Mode): محاكاة قراءات الحاويات والتنبيهات دون أجهزة فعلية
- وضع العتاد الحقيقي (Hardware Mode): استقبال قراءات من ESP32 عبر API موثوق ومصادق

- `docs/`: وثائق المشروع مثل الهندسة، النشر، إعداد الأجهزة، واستكشاف المشاكل
- `public/`: أصول ثابتة/ملفات عامة

## المتطلبات

قبل التشغيل تأكد من وجود:

- Node.js 18 أو أحدث
- npm أو yarn
- Firebase project جاهز (إن كنت تستخدم بيئة Firebase حقيقية)
- الوصول إلى بيئة ESP32 إذا كنت ستشغل الوضع الحقيقي للأجهزة

## التثبيت والتشغيل

### 1. تثبيت الحزم

```bash
npm install
```

### 2. إعداد Firebase

المشروع يعتمد على ملف إعدادات Firebase موجود في الجذر باسم:

```text
firebase-applet-config.json
```

تأكد من أن الملف يحتوي على بيانات المشروع الصحيحة مثل:

- projectId
- appId
- apiKey
- authDomain
- firestoreDatabaseId
- storageBucket
- messagingSenderId

### 3. إعداد المتغيرات البيئية (اختياري)

بعض الميزات تعتمد على متغيرات بيئة مثل:

```bash
PORT=3000
NODE_ENV=development
APP_URL=http://localhost:3000
CORS_ORIGINS=http://localhost:3000
BOOTSTRAP_ADMIN_EMAIL=mralmnjd363@gmail.com
LOCAL_SERVER_MODE=false
LOCAL_STAFF_AUTH_ENABLED=false
LOCAL_AUTH_SECRET=your_secret_here
```

### 4. تشغيل المشروع محليًا

```bash
npm run dev
```

سيبدأ الخادم المحلي ويعمل على المنفذ الافتراضي 3000، مع تشغيل Vite في بيئة التطوير.

## أوامر المشروع

```bash
npm run dev        # تشغيل السيرفر + الواجهة في وضع التطوير
npm run build      # بناء المشروع للإنتاج
npm run preview    # معاينة الناتج المبني
npm run lint       # فحص TypeScript
npm run test       # تشغيل جميع الاختبارات
npm run test:rules # فحص قواعد Firestore
```

## التشغيل في بيئة الإنتاج

لإنتاج قابل للنشر:

```bash
npm run build
```

ثم يمكنك تشغيل السيرفر كخدمة Node أو عبر خادم Web جاهز للتعامل مع تطبيق SPA.
